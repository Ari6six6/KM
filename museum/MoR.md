# MoR — the seed

- **Repo:** https://github.com/Ari6six6/MoR
- **Grade:** pretty good for its time.
- **Fossil position:** the first vertebra.

MoR was the first attempt to summon a working system onto rented hardware from a
phone. Zero-dependency Python, an `scp`-to-box workflow, and not much else — you
copied files up, you ran them, you watched. Primitive, and it did not need to be
anything more.

What MoR proved is the only thing a seed has to prove: that it is *possible.* A
man in Termux on an Android phone, renting a box by the hour, could will a system
into existence and make it run. Every ancestor after it is a refinement of that
one demonstrated fact.

The lesson MoR paid for and handed forward: **zero dependencies is a feature, not
a limitation.** A program that needs nothing but what a fresh box already has is a
program you can run ninety seconds after the box boots. KM still lives by that
law — bash + ssh + curl + coreutils, nothing else. That is MoR's fingerprint on
this repo, three generations later.

We do not vendor MoR's code here. A seed's job is done once it has sprouted. The
link above is the whole monument it needs.
